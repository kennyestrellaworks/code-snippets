# Code Snippets

This repository is a collection of mini JavaScript and UI practice projects that were reorganized into a single folder structure. The examples here are gathered from small exercises, folder restructuring, and manual solutions created before the AI boom.

## What changed

- The project was restructured so the practice examples are compiled into one main repository.
- Each mini-project lives in its own folder under the root `code-snippets` folder.
- This repository now contains both UI component experiments and focused JavaScript algorithm exercises.

## Mini practice projects included

- `accordion-component`
  - A small accordion-style UI component built with HTML, SASS, and JavaScript.
- `an-array-of-duplicate-elements`
  - A JavaScript exercise that takes an array with duplicates and pushes only unique items into a new array.
- `array-objects-into-html`
  - A simple example of generating HTML from an array of objects using template literals.
- `color-component`
  - A color palette UI component project using SASS and npm tooling.
- `font-component`
  - A font collection project that converts web fonts for use in a small front-end demo.
- `formatting-with-commas`
  - A manual number-formatting solution that inserts commas in the right places for floats.
- `sort-ascending-numbers`
  - A custom ascending sort implementation created without using JavaScript's built-in `sort()`.
- `sort-descending-numbers`
  - A custom descending sort implementation also built without `sort()`.
- `text-trim`
  - A string trimming exercise that shortens array elements longer than a defined limit.

## Notes

- These solutions are written by hand and represent the time before modern AI-assisted development became common.
- The focus is on understanding basic JavaScript logic, DOM patterns, and front-end component structure.
